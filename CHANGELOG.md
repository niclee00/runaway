# RunAway changelog

## v0.13.1 (2026-10-31)

- Hill Run: routes stay on public paths, out of schools and private grounds
- Hill Run: blocking a stop now picks a different climb, and runs land closer to your distance

## v0.13.0 (2026-10-29)

- Heart Run: hearts are now drawn on your phone along real paths, so they look like hearts and need no route server
- Pick from several hearts nearby, up to 1 km away, all under 8 km
- New Pro code

## v0.12.1 (2026-10-29)

- Heart Run is switched off for now, until it has its own route server
- Route requests are spaced out so the public route servers are not overloaded

## v0.12.0 (2026-10-28)

- Heart Run: GPS Art rebuilt around one shape, picks its own size, keeps legs near the outline, faint heart on the map; long routes stay on Valhalla; plan dialog text wraps

## v0.11.0 (2026-10-28)

- GPS Art (Pro), Hill Run finds the nearest climb, coached plans by level and phase, missed-session moves, routes avoid roads under construction

## v0.10.1 (2026-10-28)

- Hill Run and Cool Route can't be on together: turning one on switches the other off, with a note

## v0.10.0 (2026-10-28)

- Training plan: coached intake (your fitness, days, goal, style), weekly check-ins that adapt the plan, paces from a recent race, 5 km races
- Hill Run (Pro): nearest hill, sprint up and jog down repeats
- Cool Route and Hill Run: tap ? for details
- Short runs show 'Run not saved'
- Off-route buzz works in the background and with the screen off
- Avoid bridges on by default

## v0.9.5 (2026-10-28)

- Map centres on your location when the app opens
- Finishing a run clears the loop from the map

## v0.9.4 (2026-10-27)

- Generate Loop: new distance card with tap-to-type, Preferences row for extra options, first-time hint
- Run screen: Re-Center button
- Credits: HDB, LTA and Meta/WRI tree canopy

## v0.9.3 (2026-10-27)

- Cool Route: off after sunset, when every route is cool
- Cool Route: sun chip shows where the sun is and which side is shaded
- Pro unlocks with a code
- Plan: session dates as Tue - 27 Oct
- Help moved into the menu

## v0.9.2 (2026-10-27)
