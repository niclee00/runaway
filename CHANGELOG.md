# RunAway changelog

## v0.9.0 (2026-10-27)

- RunAway Pro (hidden by default): unlock from the menu
- Cool Route (beta): picks the shadiest loop and shows its shade
- Plan tab: 10 km, half and full marathon training plans

## v0.8.1 (2026-10-27)

- Run: only the next 1.5 km of route is bright; the rest, including the way back, is faded

## v0.8.0 (2026-10-27)

- New Volt look: lime accent on near-black, recoloured logo, app icon and opening animation

## v0.7.10 (2026-10-27)

- Routes never use ferries: loops no longer cross to Pulau Ubin by boat

## v0.7.9 (2026-10-27)

- Help tour: steps 2 and 3 show Generate Loop and Manual Loop selected in orange, then restore your choice
- Help tour: step 3 outlines the Manual Loop button

## v0.7.8 (2026-10-27)

- Help tour: the highlighted control now shows at full brightness
- New loop keeps the direction you chose instead of drifting
- Manual Loop: Use my location in the tip row starts from where you are

## v0.7.7 (2026-10-27)

- Update notice moved off the map controls: orange dot on Layers and an Update row in the Layers sheet

## v0.7.6 (2026-10-27)

- Locate is instant once tracking, and the first tap on the web uses a recent fix instead of waiting for a fresh one

## v0.7.5 (2026-10-27)

- Map: location dot keeps following you after Locate
- Run: chevrons on the route show which way to run
- Run: warns and buzzes when running the wrong way or going off route, with an arrow pointing where to go
- Run: buzz on/off button

## v0.7.4 (2026-10-27)

- Generate Loop sheet hides captions on short screens so it fits without scrolling
- Checks GitHub for a newer version on launch and offers an Update button
- Export to Strava shows a step-by-step guide every time; web export downloads the GPX and opens Strava's upload page
- About and credits moved into the Layers sheet on the Map tab

## v0.7.3 (2026-10-27)

- Generate Loop sheet fits a phone screen without scrolling: tighter spacing, compact controls, shorter captions

## v0.7.2 (2026-10-27)

- Generate Loop sheet: removed the static Roundtrip card, title matches the Generate Loop button, Direction row uses grey label and white value like Distance and Rounds

## v0.7.1 (2026-10-27)

- Collapsed route card shows lights, water and bridges as icons with counts

## v0.7.0 (2026-10-27)

- Frosted-glass map controls and route card, one toolbar, cleaner bottom bar

## v0.6.3 (2026-10-27)

- Route card: X closes the route, tools share the Start run row, facts on one row, bridges renamed

## v0.6.2 (2026-10-27)

- Map tab keeps your route when coming back from other tabs; tapping Map while on it clears

## v0.6.1 (2026-10-27)

- Map tab returns to the empty map (with Undo)
- Help button back on the map; tour text updated for the new layout

## v0.6.0 (2026-10-27)

- Route card collapses to one line; swipe up for details
- Map: one Layers button, compass only when rotated, lighter route markers
- Run screen: big distance, hold to finish
- Routes: Run again, area names; lighter type throughout

## v0.5.1 (2026-10-27)

- Empty map: Generate Loop / Manual Loop selector with a hint line
- Removed the Route Creator header from the map card

## v0.5.0 (2026-10-27)

- New Route Creator card on the map, with a Generate Loop button
- Plot your own route: tap the map to add points
- Map turns north and frames your route above the panel
- Runs autosave; reopen the app to resume an unfinished run
- Fresh orange accent, labelled route tools and clearer switches
- Saved routes show their shape; only water points near your route show
- Shorter tour; version on the opening screen and the About page

## v0.4.0 (2026-10-26)

## v0.3.0 (2026-10-26)
